# cdk-excavator v0.1.0

Initial public release of the review-first CLI for excavating existing AWS resources into AWS CDK drafts and explicit gap reports.

## Highlights

- Explicit pre-acquisition resource-type filters, enabled-region discovery, global-service selection, and structured stderr progress.
- JMESPath summary queries and explicit local GAP-rule overlays.
- Nested secret/read-only property exclusions, strict schema identity checks, and isolated resource-read failures with manual-review output.
- TypeScript/Python synth verification, clean npm installation UAT, and Windows/Linux/macOS arm64/macOS x64 pre-release CI.
- Portable, repeatable checksums and tag/version checks that distinguish ordinary CI from a release.

## Standalone binary trust policy

- Windows x64 is intentionally unsigned. The inherited Node.js Authenticode signature is removed before SEA injection, and release UAT requires the final status to be `NotSigned`.
- macOS Apple Silicon and Intel binaries use a valid ad-hoc signature. They are not Developer ID signed or Apple-notarized.
- Linux x64 has no platform code signature. All four binaries are distributed with `SHA256SUMS`; verify the downloaded files before execution.

These binaries do not meet a mandatory OS publisher-signature policy. The npm package is an alternative only where organizational policy permits it; npm provenance is not an OS code signature.
